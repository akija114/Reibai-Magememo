## 2. 画面構成の案

モードは `<html data-mode="easy|pro">` で切り替える（既存の `data-app` と同じやり方）。

### 初心者モード（初回の初期値）
```
┌──────────────────────────┐
│ 配管サイズ：4分（12.7mm） ▼ │ ← 大きく表示。タップで既存 #sz を開く
│ ① サイズ ② 曲げ ③ 3D確認    │ ← いまどこかの段階表示
├──────────────────────────┤
│       3D（既存そのまま）      │
│  4分・900mm・90°・↑上        │ ← 入力内容のまとめ（既存 #stInfo の欄を使う）
│  👆回転 🤏拡大（既存 .hint）  │
├──────────────────────────┤
│ 曲げの一覧（既存 #rows）      │ ← 細かい数字（シュー・累計・支持）は畳む
├──────────────────────────┤
│   ＋ 曲げを作る（大）         │ ← 既存 #add と同じ処理
│ [曲げを修正][保存する][詳細▸]│ ← 1つ目の曲げを作った後に出る
└──────────────────────────┘
```
- **＋ 曲げを作る**：既存の `openDirView` を開く。初心者モードの時だけ、その下の欄を **1つずつ** 出す
  1. 長さ（mm）→「次へ」
  2. 角度（大きいボタン、90°を目立たせる）→「次へ」
  3. 向き（既存のダイヤル＋「↑上 ↓下 ←左 →右」の矢印ボタン4つ）→「次へ」
  4. 確認（「900mm・90°・上へ」）→「✅ これで作る」
- 作った後：**＋次の曲げを追加／曲げを修正／保存する／詳細機能を開く** の4つを出す
  - 保存する → 既存の 💾 現場の保存（`#cloudOv`）を開く
  - 詳細機能を開く → 詳細モードに切替（支持・地面天井・ルートおまかせ・スキャンなど）
- 隠すもの（消さない・CSSで非表示）：🧮計算、分岐管タブ、3D右側の丸ボタン列、支持の表示、シュー以外の細かい数値
- 用語の説明：「シュー（印をつける位置）」「引き（曲げで縮む長さ）」のように括弧で一言

### 詳細モード

## 6. 計算の検証（変更はしない・確認だけ）
4分（D=12.7）、ベンダー未登録の標準＝R=4D=50.8mm で `calc()` の結果：

| 角度 | 引き＝R×角度/90 | 長さ500のシュー |
|---|---|---|
| 15° | 8.5 | 491.5 |
| 30° | 16.9 | 483.1 |
| 45° | 25.4 | 474.6 |
| 90° | 50.8 | 449.2 |
| 180° | 101.6（U幅 8D=101.6） | 398.4 |

- 実装はコード内の説明（「バック＝R×角度/90」）と一致しています
- **確認してほしい点**：3D側は角の位置を `R×tan(角度/2)` で作っています（90°では同じ50.8、45°では 21.0 と 25.4 で差が出る）。「引き」を角度に比例させるのはベンダーの目盛に合わせた現場の決まりだと思いますが、仕様として正しいか一度ご確認ください。**今回は変えません。**
- レバー式 TA540G を選んでいる人は4分のRがメーカー値 38mm になります（仕様どおり）

## 14. 天井面・床面（かんたん表示）とベンダーの対応サイズ
- 天井面・床面（`ezRoom`、表示だけ・`st` に書かない）：床は配管の床からの高さが分かる時（地面と天井の設定の基準が起点・配管・機器、または2方向カセット）はその位置、分からない時は「仮の位置」。天井高は設定がある時（天井を表示、または2方向カセット）はその値、無い時は仮に 2,200。高さ不明の時は離隔の数字を出さない。全体図の枠にも説明。表示／非表示ボタン（`pbm_ezroom`）。かんたん表示では今までの地面・天井の描画は止める（詳細モードはそのまま）
