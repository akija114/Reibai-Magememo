ふだんの流れ
  1. 📋 現場で現場カードを作る（日時・住所・メンバー）
  2. 📹 現調で写真・寸法をとる
  3. 📐 図面・3Dで図面を読み込んで3Dに。材料も拾う
  4. 📤 前日までに現場カードをLINEで送る
  5. 🔧 当日は曲げ共有で寸法を送って曲げてもらう
🔧曲げ共有寸法を入れて「これ曲げて」と頼む

できること

  • 配管の長さ・曲げの角度・向きを入れると、曲げ位置（引き）を自動で計算
  • 3Dで配管の形を見る・曲げる順番（曲げ手順）を見る
  • 持っているベンダーを登録すると、その配管の太さで使える物で計算
  • LINEなどで送る（短いリンク）・チームに送ると、だれが見たか分かる
  • 初心者モード：STEP 1〜4 の順に進むだけ（くわしい表示とデータは同じ）
  • 📐 図面の配管：図面編集から送った配管の一覧。タップするとその配管の曲げを調べる
  • 保存・元に戻す・端末に保存した現場を開く

🧊図面・3D図面を読み込んで、全部自動で3Dに

できること

  • 図面のファイル（DXF・PDF）を読み込む
  • 「全部自動」：室内機・冷媒配管のルート・壁・天井高を読む。📋 読み取りチェックで、読めた物を✓／⚠️で確かめる
  • 3D：ダクト（吹出口・フレキ）・衛生（給水・給湯・汚水・排水・通気）・ドレン・天井・点検口。🗂 表示で出す／消す
  • 🚽 下の図面：衛生などの図面をもう1枚、床に映す
  • ルートおまかせ：機器の位置から配管のルートを作る
  • 🧾 材料拾い・見積もり：配管・ドレン・電線（エアコンの種類で変わる）・単価表

✏️図面編集図面を直す・寸法・メモ・機器を動かす

見る・選ぶ

  • レイヤーを空調・ダクト・衛生などのグループで出す／消す
  • 部品をタップで選ぶ・長押しで追加・「範囲」で囲んで選ぶ

書きこむ

  • 寸法（芯出し：通り芯・機器の芯・壁から）
  • メモ：置く前に赤い印で場所を確かめる・置いたメモは指で動かせる
  • 1から冷媒配管・ドレン配管を引く（高さも区間ごとに）。🕳 壁の貫通部を置いて「室内機ぜんぶ引く」で、室内機ごとに穴を通る冷媒とドレンをまとめて引く（ドレンは下り勾配 1/100）。配管が壁を通る所には自動で貫通部が付く。貫通部はタップで直す・消す。始点・終点の丸は指で動かせる
  • 🏷 形を登録：部品をタップ →「これは何？」→ 上の欄を見ながらタップ・⬚ 囲むで形ぜんぶを選んで「OK」→ 壁・扉・室内機・点検口・吹出口・柱・窓・階段・ベッド・家具（3Dに出さない）を選ぶと、同じ形を図面ぜんぶから探して3Dにその種類で出す。端末で覚えて、ほかの図面でも使う。3Dの上の「（登録 N）」のボタンで種類ごとに出す／消す。登録した形は一覧に絵が出て、絵をタップで大きく見られる
  • 🗺 拡大している時は右上に全体図。オレンジの四角をドラッグすると見る所が動く。右へスワイプ（または「›」）でしまい、右の端の「🗺」で出す
  • 🧊 3D：壁は図面の斜線で塗った壁を読む。扉（開き戸の印）は扉の高さ・幅だけくり抜いて、上は壁が続く。室内機は機種の模型（三菱 GE-MP1080M など）で、図面の機械の形ごとに機種を選ぶ（品番が書いてない時は聞く）。模型は図面の本体に重ね、配管の口は図面の配管の出る面へ向ける

機器を動かす（✥ 移動）

  • 指でずらす・数字で mm・芯に合わせる
  • 回す：90°ずつ（↺ ↻）・好きな角度（30°・45°など）
  • 📐 壁の向きに合わせる → 壁から○mm 離して置く／2枚の壁の真ん中に置く
  • 回しても、つながった配管・ダクトはついてくる（機器をよけてつなぎ直す）

部品をなおす

  • 🗂 レイヤーを変える・⧉ 複製・撤去（点線の×で残す）・非表示・削除

3D・送る

  • 🧊 3D：図面編集の中で3Dを見る。「曲げ共有へ」で配管を曲げ共有に送る
  • チームで同じ図面を見る・図面のファイル（DXF・PDF）で書き出す
↶ で、たいていの操作は元に戻せます。

📹現調現場で写真・寸法・メモ
  • カメラの映像に、配管・機器の3Dを重ねて見る
  • 📍 2点でルート：カメラの画面で ①室内機の真下の床 ②穴の真下の床 ③穴（見えない時は ±で高さ）をタップ → 配管ルートの案（L字・まっすぐ）がだいたいの長さで出る。「次のルート」で切りかえ・「曲げに入れる」で曲げ共有へ。「🧊 床に固定して見る・写真を撮る」で、室内機・ルート・穴を実物大で床に置く（置いたら歩いても動かない・その画面で写真）。立ったまま動かずに使う（⚙で天井・スマホの高さ）。🔩 で室内機の機種（配管は機種の配管の口から）・↻ 回す → 🔓 決めると固定・👁 全体／パネルだけ・📏 天井をタップして天井の高さ・だいたいの寸法・📷 写真
  • 🧊 機器を実物大で置く：床をタップして機器だけを置く。壁の側と「壁から○mm」を決めると、灰色の壁の板が出る → 本物の壁に合わせれば、その距離で機器の位置が決まる（天吊・床置き・壁掛けは機種から）
  • 寸法の計算・機器の模型を置く・配管の太さを選ぶ
  • 現場情報のメモ・保存して送る
現調を開く
📏写真に寸法撮って、なぞって、数字を入れる
  • 写真を撮る（または前の写真を選ぶ）→ 測った所を指でなぞる → 数字を入れる。それだけで寸法の線が残る
  • 「梁下」「天井高」「壁から」などはタップで頭に付く。💬 文字で「点検口」「障害物」などのメモも置ける
  • 書いた線・数字はタップで直す・消す。↶ で1つ戻す。2本指で拡大すると細かい所もなぞれる（指の下は上の丸に大きく出る）
  • 「送る」で、線と数字を書きこんだ写真をLINEなどへ。「…」で現場を決める・寸法をコピー
写真に寸法を開く
🔩機器・📘 空調の種類と電線品番でさがす・分からない時に調べる

機器をさがす

  • 品番で大きさ・模型をさがす（ハイフン・空白はちがっても、一部だけでも探せる）
  • 無い品番は「調べてほしい品番」に残る → 教えてもらえれば登録します
  • 🧊 模型と寸法：指で回す・2本指で大きく。斜め／上から／配管の面／横／下から。本体・吊りピッチ・ネコ・配管の口の高さ・全ねじから口まで（内へ／外へ）・パネル・開口の寸法。パネル・吹出口は3Dと同じ形。ロスナイも模型と寸法（ダクトの口・ダクトピッチ）

📘 空調の種類と電線

  • 方式（ルーム・パッケージ・ビルマルなど）・室内機の形・換気・関連設備
  • 電源・連絡線・伝送線・リモコン線を線の絵で（目安。最後はメーカーの説明書で確かめる）
  • 施工手順：エアコンの入替工事（5つの段階）・持っていく道具と材料
  • ヒートポンプのしくみ・集中リモコン・ドレン・冷媒配管の保温

📋現場現場カード・週の割り振り・人工・社員

現場カード

  • 日時・住所・駐車場（場所・写真）・メンバー⭐・作業内容・持ち物
  • LINEに送る文章を自動で作る・チームに送ると、だれが見たか分かる
  • 日程は続けて、または飛び飛び（📆カレンダー）・昼／夜・人数（最低○名＋余裕）・応援さん・交通費

📅 週の割り振り

  • だれがどの現場か・休み・空いている人・足りない現場が色で分かる
  • 表のマスをタップで入れる／外す・休み・残業。週の割り振りをLINEで送る
  • 🏢 会社で一緒に見る：社長が会社を作って招待のリンクを送る → 社長・番頭が「直せる」か「見るだけ」で許可。名前はニックネーム、個人情報は送らない。残業・交通費・人工は社長・番頭だけ

📊 人工・残業

  • 締め日ごとの1か月・1年。日勤・夜勤・休日出勤・残業・交通費を人ごと・現場ごとに

👤 社員・個人情報

  • 名前は名字と名前に分けて入れる（ふりがなも）
  • 直して戻る時に「保存しますか？」（保存しない＝元にもどす）。🕘 変更の記録からもどせる（消した人も）
  • タグ（溶接・電気工事士など。🙈で隠せる）・個人情報・緊急連絡先・資格証の写真
  • 文章・資格証の写真・ファイルで相手に渡せる
  • ニックネーム・会社名・職種と経験年数。🤝 協力会社は会社ごと（社員⇄協力会社は一覧のボタンで移す）
  • 📇 スマホの連絡先に入れる（1人ずつ・社員みんな）
  • 📇 スマホの連絡帳から読み込む（確かめてから入れる・足りない所を赤で教える）
  • 🩺 健康診断の日・血圧。1年過ぎたら赤で「更新してください」
